# NeuroNexus


Assignment Submission – NeuroNexus Task

This is the assignment given by NeuroNexus, where I was asked to create a Google Form-like web form using only HTML and CSS, without using any JavaScript. I have built the form from scratch and incorporated all the required elements as specified in the task.

✅ Features Implemented:
Full Name (Text Input)

Contact Number (Phone Input)

Address (Multiline Textarea)

Company Name (Text Input)

Email Address (Email Input)

Department (Select Dropdown with options: HR, Sales, Development, Marketing, Others)

Gender (Radio Buttons: Male, Female, Prefer not to say)

Submit Button

🌟 Bonus Enhancements (Optional Points):
A simple hover effect has been added to the submit button for better user interaction.

The form's background color is distinct from the page background to improve visual separation.

A minimalistic box-shadow has been applied to the form to give it a subtle elevation effect.

This project demonstrates the ability to create interactive, styled, and accessible forms purely with HTML and CSS, following UI best practices without any use of JavaScript.
